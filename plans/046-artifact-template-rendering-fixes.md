## Steps

### Step 1: plan-pages template — theme-aware controls, chip wrap, chip placement

In `plugins/plans/skills/plan-pages/TEMPLATE.md`:

1a. Inside `:root {`, insert `color-scheme: light dark;` as the first
declaration (before `--geist-bg: #ffffff;`). Do NOT add it to the dark
`@media` override block — one declaration serves both schemes.

1b. In the `body {` rule, after `-webkit-font-smoothing: antialiased;`,
add `accent-color: var(--geist-fg);`.

1c. In the `code {` rule, after `padding: 1px 5px;`, add:

```css
overflow-wrap: anywhere;
-webkit-box-decoration-break: clone;
box-decoration-break: clone;
```

1d. In the `@media (max-width: 640px)` block, replace the `.step` /
`.status` pair quoted in "Current state" with:

```css
.step {
  grid-template-columns: 32px minmax(0, 1fr) auto;
  gap: 10px;
}
```

(the `.status` override is deleted — the chip stays in the third column,
top-right, at every width).

**Verify**:
`grep -c "color-scheme: light dark" plugins/plans/skills/plan-pages/TEMPLATE.md` → `1`;
`grep -c "box-decoration-break: clone" ...TEMPLATE.md` → `2` (prefixed + standard);
`grep -c "grid-column: 2" ...TEMPLATE.md` → `0`;
`grep -c "accent-color" ...TEMPLATE.md` → `1`.

### Step 2: decision template — same 1a/1b/1c

### Step 4: DESIGN.md §6 — make the rules contractual

In `plugins/DESIGN.md` §6, directly after the bullet

```markdown
- Declares `color-scheme: light dark` in `:root` and

  the chip outline. Status/progress chips keep their top-right slot at

```

**Verify**: `grep -c "box-decoration-break" plugins/DESIGN.md` → `1`.
